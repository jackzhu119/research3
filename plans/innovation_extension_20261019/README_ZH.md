# 论文3：补强创新证据的前瞻方案

本次准备的是可证伪的实验方案与近邻文献审计，尚未运行实验、产生科研结果或证明“首次”。原 H1、主11输入、source/development分组和原受控pilot保持原样；本文件不授予外测query权限或新GPU预算。

最值得优先增加的是**双方字典互换的机制验证**，让结果区分“学到的空间方向有效”“矩阵映射本身有额外价值”和“只是正则/头更新带来收益”。更多数据、矩阵指数、PCT、LoRA或一张脑地形图本身都不能替代这个证据。

## 近期近邻会改变哪些创新措辞

本轮有界检索实际读了6篇直接近邻和2篇上下文，保留原始响应与SHA。

- Lopes等，*Learning aligned EEG representations with subject-specific encoders*，Scientific Reports 2026-09-03公开的已接收/同行评审早期版本：[DOI](https://doi.org/10.1038/s41598-026-69220-z)。作者[arXiv v3](https://arxiv.org/abs/2606.16462v3)已有首会话前48个有标签trial适配。不能主张首次低秩空间adapter或首次前缀少样本；摘要2Cr低秩参数化与公开正文/所查代码的对应仍有缺口，不编造实现。正式接收版与作者v3状态分开记录。
- Manivannan与Lakshminarayan，[arXiv:2511.18940v3](https://arxiv.org/abs/2511.18940v3)，为预印本：已有几何congruence、反对称矩阵指数旋转及合成扰动。不能主张首次矩阵指数或可逆几何EEG适配。其整目标无标签统计不符合本协议query封存规则；若移植仅support版，必须标为移植版而非原法忠实复现。

现有B6是自由空间LoRA，B8是独立元训练learned-additive，B9是random-exp；B4/B5是传统CSP/切空间方法。不能因方法家族类似就说B6已精确复现2026新论文。最有希望检验的具体差异仍是：开发纵向episode学到的少数参考一致、幅度受限空间方向，在20个真实经过的前缀trial之后，是否改善未来完整块，并解释收益边界。该差异的有效性和文献独创性均未由本次检索确立。

## 如何安排到后续算力

不额外重训source或G；复用未来W4–W6真正生成并通过哈希门的f0、Rref、P/B8及强对照。先用元数据顺序固定的至多2名validation参与者、1条原seed、每人1个真实session检查数学、恢复、有限值和实际成本；推进标准不看是否提升准确率。扰动只采用双方唯一已冻结ρ的较小值乘以0.5/1.0，不重新遍历ρ网格，各方法的拟合半径保持原冻结值。17个条件/episode包含一个共享零剂量条件；该小panel最多204次目标拟合、2040次内层梯度更新，是静态上限而非已授权预算或运行记录。

完整备选上限为每人每pipeline至多1个episode：11名validation参与者×5条pipeline×17条件×最多6个需拟合方法=5610次目标拟合，最多56100次内层梯度更新；传统闭式方法按实际求解记账。重复人工视图、session、trial和seed不增加独立N。没有测过运行时间，不能许诺GPU小时；附加预测同样计时计费。审查文件含备选小panel，本版所采纳设计以plan.json为准。

优先保持原READY主11受控pilot不变。新实验入口尚未实现，任何实际执行都要等待用户手动开机、相应native/source/development产物与单独有效预算。内部留出不反复用于选择这些分析；外测仍按W7算法seal→受控native资格→队列/比较族seal→预先保存预测的顺序。若以后纳入外测，同M反事实预测也必须在揭示外测标签前生成；不能在W9看到结果后悄悄改模型重跑。

## 结论怎样随结果收缩

若P与B8接近而均胜过随机方向，贡献只能落在学到方向，不写矩阵指数性能优势；若收益仅在PCT出现且不超过B7/B11，不能归给新空间机制；若均值主要由一人支撑，明确不稳定；若只在本家合成扰动获胜，不外推真实临床生理因果。失败与无效条件同样保留。

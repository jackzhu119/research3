# Paper3 第九轮：有限支持信息下的源预测残差校准

本轮根据第2、3、7轮完整CSV的实测结果设计，研究冻结EEGNet的函数残差与信息锚定，区别于第八轮协方差运输。状态为**设计与开发环境验证，未提交学校作业，没有第九轮效果结论**。

## 已有结果如何决定新方向

第七轮平均有效支持仅15.53个，却适配65个head参数。同一主体下，head rank0到64使支持BCE从.672降至.121，未来BA却从61.31%降至56.84%；EA仍达到62.21%。这支持优先研究有限标签下的过拟合与外推，而不是只增加空间变换参数。原主要比较没有证明第七轮方法显著胜出。[完整复核与来源](evidence/RESULTS_FOR_R9_ZH.md)。

## 候选算法与验证

在源logit均值上拟合至多20维支持空间的残差GP；比较同一核、同一MAP和同一超参数下的MAP、后验积分、固定混合权重与局部信息权重。主规则为 q=(1−.75r)p0+.75r·pGP，其中r是支持使该位置残差方差减少的比例。零信息回到锚定预测；这不保证未来准确率提高。

保留源模型、EA、head-SGD10/100、源/EA温度.5和2等对照。原输入与EA后输入独立建立训练域特征参考；超参数只用meta_validation选定。内部/Pan/Weibo已被多轮查看，全部标为探索性重复使用，不称新增盲测。[完整设计](DESIGN_ZH.md) · [数学与正式文献](design/math_review.md) · [统计规则](STATISTICS_ZH.md)。

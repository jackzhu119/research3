# R11 test migration

R10 remains unchanged and retains its original tests. The R11 copy retains R10 numerical/profile tests because that method is a baseline. R10-only tests requiring a nine-candidate PASS freeze and formal cross-package transfer were replaced: R11 has a predeclared campaign DAG, whole-candidate exclusion, immutable selection, explicit role separation and no performance veto. Those obsolete cases do not describe R11 behavior and were not used to restore unwanted startup gates.

New R11 tests cover the exact permutation identity and balanced covariance collapse, all operator constraints, global empirical bounds, partial feasible solvers, native source/cache formats and three-seed baseline paths, selected-vs-independent tuned artifact joins, a complete small campaign, 10,270-task planning, persistent Torch import/error isolation, checkpoint signals, cached scheduling, and incremental independent upload recovery. Software fixtures are not EEG efficacy evidence.

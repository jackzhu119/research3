## 1. 要回答的科研问题

继续围绕论文3的任务：**只使用新会话最前面的20个已采集试次，校准已训练的紧凑 EEGNet，并预测该会话后面的完整物理运行段。** 不把任务改成随机划分同一会话，也不重训全部源模型。

建议论文主线为：**有限校准证据下，空间调整的类型、教师约束的强度和未来时间段风险，应当如何共同影响少样本运动想象识别？** 三个可独立检验的问题分别是：

1. 同样20个试次，对“反对称生成元”和“对称生成元”的调整是否需要不同强度？
2. 原源模型在当前支持集表现不可靠时，固定的保护原预测约束是否会阻止有效适应？
3. 优化平均未来损失是否掩盖少数表现很差的后续物理运行段？

这三个方向分别对应**平均效果、减少新错误、时间稳定性**。即使平均准确率没有显著提升，也可能得到有边界、有重复证据的结论；不能把未显著提升改写成“全面有效”。

## 4. 方向A：支持集条件化的两种空间调整

设原方法学习的字典为 `B ∈ R^(99×r)`，`BᵀB=I`；`E`为10×10无迹矩阵空间的正交基。内层参数为θ：

```
M = reshape(E B θ, 10, 10)
S = (M + Mᵀ)/2
K = (M − Mᵀ)/2
M' = α_s S + α_k K
A = Qᵀ R_ref^(1/2) exp(M') R_ref^(-1/2) Q
```

在白化后的10维CAR子空间内，对称部分对应增益/形状变化，反对称部分对应旋转生成元。`exp(S+K)`一般不能拆成彼此独立的旋转与缩放乘积；不把这解释成真实电极位移的直接测量。

`(α_s,α_k)=sigmoid(W[e;1])`，只依赖当前支持集的6个无梯度证据特征：

1. 支持集相对源参考的白化对数协方差偏移；
2. 按类别交错分半后两份协方差的分歧；
3. 冻结源模型的支持集类别平衡交叉熵；
4. 源预测熵；
5. 支持集类别不平衡程度；
6. 有效试次/实际采集试次比例。

协方差用5%向单位迹球形矩阵收缩；幅值用`x/(1+x)`压缩，不在验证/留出集拟合归一化。初始门值0.9，W非偏置部分为0。**“门”仅是连续数值权重，不是阻止作业启动的规则。**

两门仅增加14个全局元学习参数，目标会话仍只更新r维θ和原线性头残差；不再为每个会话训练一个网络。外层更新W，支持集特征自身detach，梯度经过完整内层优化。

可验证的结构性质：

- `tr(M')=0`，故10维`det(exp(M'))=1`。11维CAR映射本来秩亏，不能声称其行列式为1。
- S与K在Frobenius内积下正交；若α在[0,1]、`||θ||≤ρ`，则`||M'||F≤ρ`，因此白化空间中`κ₂(exp(M'))≤exp(2ρ)`。
- 在`B→BO, θ→Oᵀθ`的正交换基下，M及分解不变。

这些性质约束变换幅度，不保证提高分类准确率。门值也可能几乎恒定，因此必须比较`global`常数门、`scalar`单条件门、`dual`双条件门；如果dual不优于global，证据不支持“当前会话证据有额外价值”。

## 5. 方向B：按支持集可靠性调整教师约束

保留原PCT形式与总系数λ=0.1，改变逐试次教师权重。原权重为`1+5×I(教师判对)`，新的权重为：

```
r_i = (1 + 同类支持试次判对数 − 第i个是否判对) / (同类支持试次数 + 1)
w_i = 1 + 5 r_i p_teacher(y_i|x_i) [1 − H(p_teacher(x_i))/log(2)]
L_inner = L_balanced_CE + 原正则 + 0.1 mean(w_i * ||logits_i − teacher_i||² / 2)
```

`r_i`为Beta(1,1)模型下去掉自身后的平滑正确率估计，减轻单个支持样本自证可靠。只读取当前支持标签；不使用未来查询标签，也不额外训练教师集成。

预期：当源模型当前会话不可靠时，减少对错误或低置信度教师的强保护。可能失败：可靠性估计仍有噪声；减弱约束导致新的错误；或者原PCT已经足够。以`softPCT vs PCT`检验，必须同时报告准确率、负翻转和纠错率。另设`softPCT_mean`：把该支持集所有权重固定为同一值mean(w_i)，保留相同平均教师约束强度。只有softPCT优于这个对照，才支持“逐样本可靠性分配”优于“仅减弱总约束”；这是本次复核补上的关键混杂控制。

## 6. 方向C：真实未来运行段的平滑尾部风险

保持同一会话的原始时间顺序，先用前20个已采集试次适应，再对后续完整物理运行段计算查询损失。外层训练目标：

```
L = 0.75 L_all_future_balanced
    + 0.25 τ log(mean_j exp(L_future_run_j_balanced / τ))
τ = 0.5
```

仅纳入有左右两类样本的完整物理运行段；不足两个这样的运行段时自动使用原均值损失，保留该训练episode，不中断作业。记录这种退化分支所占比例。缺失物理运行段身份时不人为伪造时间窗口。

新假设是“同一校准前缀对后续不同时间段的适应并不均匀”；评价未来运行段BA的第10百分位和均值。该目标并不保证某个BA分位数提高；如果多数会话没有至少两个合格运行段，必须说明此方向证据不足。

另设`runmean`：把尾部项改为合格运行段损失的普通等权平均，其余0.75/0.25混合不变。temporal优于runmean才支持尾部倾斜本身，避免把试次权重改成运行段权重的收益误算为风险优化。

另外预先加入`dual_temporal`，只检验两个机制能否叠加。若叠加无收益，不再根据留出结果临时拼装更多组合。

## 7. 一次提交的扩展矩阵

三个完整流水线种子20261018、20261019、20261020；核心固定r=4、ρ=0.15。中间配置不是事后认定的最优点。

| 方法 | 改动 | 可检验的作用 |
|---|---|---|
| P | 原空间子空间 | 匹配基线 |
| global | 两个全局常数门 | 是否只是固定收缩 |
| scalar | 一个支持条件门 | 条件化但不区分成分 |
| dual | 两个支持条件门 | 对称与反对称成分分别调整 |
| symonly | 只保留对称生成元 | 形状/相对增益成分对照 |
| skewonly | 只保留反对称生成元 | 旋转成分对照 |
| PCT | 原硬正确性权重 | 预测保护基线 |
| softPCT | 平滑可靠性逐样本权重 | 教师失配时如何保护 |
| softPCT_mean | 同一支持集软权重均值 | 排除总约束强度变化 |
| temporal | 后续真实运行段倾斜损失 | 时间段稳定性 |
| runmean | 后续运行段普通均值 | 排除运行段重新加权 |
| dual_temporal | dual加temporal | 预先指定的组合 |

**36个核心元训练任务＋24个敏感性元训练任务＋6个无元训练参考任务＝66个逻辑任务，最多3卡同时运行。**

敏感性任务：P/dual × {(r=2,ρ=.15),(r=8,ρ=.15),(r=4,ρ=.05),(r=4,ρ=.35)} × 3种子。加上核心中间点，一次获得秩与幅度的两条单因素曲线；不扩成昂贵全笛卡尔积，不根据留出曲线选“最佳参数”。敏感性任务只评价B20。

两个参考各3种子：`head_only`固定空间，仅在支持集做原10步残差头更新；`support_EA`只从支持集估计单位迹协方差并作5%收缩，以源参考重着色，零元训练、零目标标签拟合。后者是“支持集收缩协方差对齐参考”，并非完整复现原EA论文。冻结f0由同次预测直接形成参考，无需新增任务。比较时明确support_EA不含头校准，因此不能把它与dual的差异全部归因于空间机制。

所有60个元训练fit均1000外层步，每步4个先按人再按会话均匀采样的episode；内层10步完整可微SGD，每50步验证。B沿用Stiefel更新lr=.01；θ lr=.05、头lr=.01及原正则不变。门参数改用functional Adam(lr=.003, β=.9/.999, ε=1e-8)，所有学习门的方法使用相同优化器，并将两个动量和步数存入checkpoint。

原因：软件随机夹具发现门梯度可能只有约4.7e-8，原SGD .01几乎不移动；它不是实际EEG效果估计，但足以暴露实现可训练性的风险。现在记录门梯度、每步变化、相对初始化变化及跨episode门值方差；Adam也不能保证真实数据上门一定有用。

逐episode累积4项完整高阶梯度，释放上一计算图，避免为了并行而把batch改为12。symonly/skewonly同时改变可达子空间和变换能量，结果只能支持成分消融，不能直接证明真实电极位移或纯粹因果机制。

已有同配置P/PCT完整结果可复用；核心最多6个、敏感性P最多12个，共最多省18个元训练fit。实际复用取决于现有完整产物、种子、r/ρ和数据/源模型匹配，不预先计为完成。其他方法从新目录训练，不覆盖现有实验。

## 8. 训练选择、评价和显著性

- 仅元训练参与梯度；验证集按“受试者等权BA最高→平衡交叉熵最低→更早步数”选择checkpoint。
- 保存`selected.json`后才载入内部留出会话，不用留出结果选择训练checkpoint或超参数。
- 主终点：B20内部留出受试者平均BA；先在每人内对相同会话和3个种子平均，再进行受试者配对比较。
- 预先固定10个核心比较：dual−P、dual−scalar、dual−global、dual−symonly、dual−skewonly、softPCT−PCT、softPCT−softPCT_mean、temporal−P、temporal−runmean、dual_temporal−dual。整体Holm校正，不把未校正p值称为显著。
- 报告绝对差值“百分点”、配对受试者bootstrap95%CI、配对符号翻转检验p、Holm校正p。符号翻转检验依赖零假设下差值符号对称，并非随机临床试验的随机化保证。CI是各比较的未同时校正区间，不能写成家族同时置信区间。
- 同时报相对误差下降`(BA_new−BA_old)/(1−BA_old)`，不能把+2个百分点写成“提高2%”而不说明定义。
- 辅助描述指标：相对f0的类别平衡负翻转率、纠错率、未来真实运行段BA最小值/P10、受试者退步比例、支持集校准时延、门值/门梯度，以及类别平衡NLL、Brier、固定10箱ECE。保存逐试次概率，可复用结果作后续误差分析。少量运行段P10是插值描述，不是可靠的人群尾部风险估计；ECE在小样本上也有估计噪声。
- 少样本曲线B=4/8/12/16/20：只截短同一个已采集前缀，始终评估B20定义的同一组后续查询试次。无效试次仍计入采集预算，不免费补齐。需要有监督内层的方案遇到单类别支持时沿用f0并报告比例；无监督support_EA仍可用已有有效信号。预算曲线代表B20元训练参数迁移到较短前缀，不代表每个预算分别训练后的最优解。
- 辅助指标及分组图是探索性描述；不能在10个BA比较失败后改成新主终点。矩阵在本轮执行前固定，但不宣称已在第三方平台预注册。核心36任务齐备后才给10比较的Holm推断；未齐时仅给部分描述结果，避免不断窥看p值。敏感性、短预算、参考和扰动比较仅给配对差及95%CI，不作未经校正的显著性宣称。

只有11个内部留出人，统计功效有限。例如配对人间标准差约5个百分点时，未考虑多重比较的粗略80%功效可检测差值约`(1.96+0.84)×5/sqrt(11)≈4.2`个百分点；小样本精确检验和Holm会进一步改变这个量级。此例不是本数据的功效估计，更不是承诺能检出1–2个百分点。

**现有内部留出集已经属于前一轮研究体系。本轮属于内部重复验证，不把它重新包装成全新未见外部测试。** 真正更强的论文证据应在方法冻结后增加独立队列/数据集，且确认输入通道、标签、任务和人群是否可比。现有扩展数据结果若已用于设计，只能算稳健性补充；不把重复使用的数据称为外部盲测。

## 9. 一次运行额外取得的机制与稳健性数据

核心P、dual、PCT、softPCT、softPCT_mean各3种子，在固定已选模型上执行6种诊断，无新增元训练：

- 支持标签翻转10%、20%：固定同一会话采样顺序，仅改变支持标签；后续查询标签保持真实值。记录实际被翻转UID和数量。反映少量校准误标，不能当成真实自然标签噪声的发生率。
- 支持完成后的查询增益漂移：CAR子空间内无迹对称对角生成元，Frobenius范数0.10/0.25。
- 支持完成后的查询旋转漂移：CAR子空间内反对称生成元，Frobenius范数0.10/0.25。

空间扰动是Qᵀexp(D)Q作用于后续查询信号，支持集保持原始；各方法/种子使用同一个物理坐标扰动，同一类型两档共享方向。强度是无量纲生成元范数，不写成10%电压或10度旋转。检验的是校准后的未知漂移鲁棒性，不能称作算法看见漂移后主动追踪。预测时不读取查询标签，不修改原缓存。

由此可以回答：可靠性保护是否更怕误标；双门收益是否仅出现在某种漂移；平均BA、负翻转和概率质量是否发生权衡。所有诊断预先固定，不根据结果增加更容易胜出的扰动。

暂不塞入本批：跨会话历史记忆（改变信息预算）、新大骨干（混入预训练资源差异）、全新外部队列（需先核对真实输入可比性）。这三项适合有清晰主结论后扩展。多任务本身不是创新，最有价值的是**在固定前20试次的信息预算下，解释哪种可观测证据值得改变哪种空间校准，以及什么时候保护旧模型反而阻碍适应**。

最新边界补充：TCPL已研究EEG任务条件提示[12]，TFTL已使用目标无标签休息数据辅助个体迁移[13]，LUMA已研究线性化元学习中的低秩先验和任务不确定性[14]。因此不能宣称首次条件化、首次低秩或首次不确定性适应；当前6项证据只是可解释代理量，不是校准后的贝叶斯不确定性。是否构成足够新颖贡献仍由具体机制、实证和更完整查新共同决定。

## 10. 顺畅执行、断点与日志

本次使用独立的直接worker与Slurm数组，训练图中没有旧campaign的多层回执审批、备份审批或全库重验证链。复用已存在源模型、缓存和数学内核；只读必需的小型输入清单及实际用到的数据。

| 之前出现的问题 | 本轮处理 |
|---|---|
| train之前又跑约4800项pytest、pilot、全库SHA | 提交路径不调用这些步骤；软件测试在开发时完成 |
| 12小时累计墙钟限额 | 不设置累计12小时限制；外层1000步是实验预算，不能无限改变比较训练量 |
| Slurm本身有单作业时限 | 使用现有5天3小时上限；提前300秒发USR1，保存后尝试requeue。学校是否允许自动requeue取决于集群；不宣称能覆盖管理员强杀 |
| 断后从头开始 | 每10个外层更新存一次、验证前后各存一次；两代checkpoint和最后写入的指针；读坏的最新代时回到上一代 |
| 验证到一半中断 | 各会话预测单独保存，参数与数据身份匹配则复用；先前1000步训练不重跑 |
| 不能创建硬链接/特殊原子目录重命名 | 普通同目录临时文件+文件fsync+os.replace；不依赖renameat2/目录fsync支持 |
| 作业运行但网页没日志 | shell第一行即输出TRAIN_PROCESS_STARTED；Python无缓冲；30秒心跳给出阶段、实际outer_update、验证会话计数；异常完整traceback进入out和error.json |
| 网络下载/上传超时影响训练 | 不下载数据；GitHub由独立登录节点监控器每180秒同步，失败继续重试，训练进程不等网络 |
| 一项错误取消后面全部任务 | 独立数组元素；其他任务继续。重跑同一启动命令只补未完成元素；只补未完成且未运行的数组元素；新补数组等待旧数组结束，保持全局最多3卡 |
| 修复日志导致checkpoint身份变化 | 日志、监控、提交等运行代码不属于数值recipe；算法/数据选择真正变化才另起实验输出 |

状态包含B、门参数、步数、最佳参数、验证历史、Python/NumPy/Torch随机状态、数据/源身份。门Adam的步数及一二阶动量一并保存；B与会话内层保持原SGD。在实际cu121发行包上的CPU逐位恢复测试通过；学校GPU上的跨节点逐位恢复尚未实测，不能提前保证。

突然掉电/进程被强杀时，通常重做上次保存以来至多9步；若最新文件损坏而退回上一代，可能额外重做一个保存间隔。共享存储彻底损坏并不由checkpoint自动解决。真实数值错误仍会终止该元素并保留错误和状态，不能将坏结果静默当成成功。

提交请求每个元素24CPU/1GPU。一个元素完成全部训练选择和B预算评估后，调度器补入下一个；避免训练过短后GPU在固定“方向专属槽”闲置。小算法不采用DDP；4个episode也不会被错误扩成12个以改变全局batch。

## 11. 时间与完成判据

旧日志中一个B8任务1000外层更新约57.3分钟，仅作量级参照。若60个元训练任务都与其等时且持续3槽，约19.1小时；若18个匹配基线均能复用，元训练部分约13.4小时。这个算式不含额外预算评估、90组扰动评估（15个模型×6）、参考任务、排队和共享存储等待，**不是本轮实测ETA**。安排至少数天窗口更合理，真实时间在首批任务完成后估算；不为估时再做独立pilot。

本地每30秒报告阶段和实际更新/评价会话；GitHub每180秒同步。部分完成即更新描述性报告，全部核心齐备再产生主比较；66项及报告均完成后形成最终结果。任务完成比例不是墙钟时间比例。GitHub失败只排队重试，不中断模型。此版本独立写monitoring/paper3-followup-v2/status.json，避免覆盖可能正在运行的旧版状态。

## 12. 实验交付和解释标准

最终输出：66项结果（60个元训练配置和6个参考任务）、逐会话真实预测概率、两代断点、选模来源；`report.json`及`comparisons.csv`、`budget_curves.csv`、`budget_comparisons.csv`、`reference_comparisons.csv`、`sensitivities.csv`、`diagnostics.csv`、`diagnostic_comparisons.csv`，以及GitHub状态页。每个文件保留任务/种子/模型选择来源。

- dual优于P、global、scalar：支持“条件化的两个生成元强度比统一缩小空间更新更有效”。
- dual仅优于P但不优于global：收益可能主要是固定收缩，不能宣称支持集推断机制获得证实。
- softPCT优于同平均强度对照且降低负翻转：才更支持逐样本可靠性分配。BA下降不显著不能当成已证明非劣；若要正式非劣结论，需要事先有理由的界值与相应区间。
- temporal优于runmean并改善后续段尾部：更支持倾斜项本身。均值持平只能描述观察，不能自动证明不会损失准确率。
- 合并无增益：可能共享同一噪声/漂移来源，保留这一负结果。
- 全部无提升：检查门梯度、时间段覆盖、配对置信区间；报告该数据/预算下的边界，不在内部留出上反复调到显著。

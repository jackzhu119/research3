# 少样本空间校准为何发生负迁移：受控机制验证设计

设计日期：2026-10-27。状态：**已实现独立M12执行包并进行本地CPU验证，尚未提交学校作业或产生新EEG结果**。独立研究目录，不修改R1–R11的科研代码、作业或结果。它可作为下一轮机制研究，暂不以新增算法名称包装已有Fisher、Schur、PCA、正则化或信赖域。

## 1. 唯一主问题与可证伪假设

**在相同适配容量和相同参考预测改变量下，支持集约束较弱的空间更新方向，是否仍更容易损害固定未来query的预测？这些方向是否真实参与了原生更新，而非研究者事后人为加入的噪声？**

候选解释必须竞争：

1. **方向解释**：支持集对某些方向约束弱，强拟合把误差带入这些方向，支持之外的预测被放大。
2. **容量解释**：任何低容量更新都更好，方向选择并无独立价值。
3. **幅度解释**：收益主要来自少改预测；普通缩小更新即可解释。
4. **head解释**：问题主要发生在可吸收支持变化的分类头，而非空间适配本身。
5. **前缀代表性解释**：支持与未来的空间变化并不相同，即使拟合方向正确也无法迁移。

本研究的候选贡献是对这些解释的成组干预证据。观察到相关性、加入零空间噪声后变差、或重新做一次head秩扫描，都不够构成所述机制的验证。

## 4. 共同数学对象

令mθ(x)为冻结EEGNet加空间适配后的二元margin，θ=0对应EA anchor。采用一份**已完成R7的4维生成元字典**，但主实验明确使用已有`mode='static'`的完整生成元空间映射：M(θ)=reshape(E B θ)，Tθ(Y)=exp(M(θ))Y。保留原CAR/源参考白化坐标以及最终trial-RMS归一化；θ=0与共同EA anchor的数值路径一致。这是从原R7时空实验转入纯空间的预定新干预，不声称是在重跑原R7的时空relative_dro方法。具体字典/geometry/source检查点SHA在学校一次性导出时写入冻结记录；缺少该身份时本设计仍是草案，不能假称已锁定实物工件。不得使用仍在训练的R1字典作为隐式依赖。

这些生成元在原参考白化坐标中Frobenius正交；所有方向条件共享同一4维参数族。第二份既有字典仅作为冻结后的敏感性实验，不能按目标结果替换主字典。

不能把原时空生成元M=K+S中的时间项删去后只使用K，却仍称原四维字典正交且满秩。主映射使用完整M，避免这个容量与几何混淆。

主实验**不训练分类头**。支持Jacobian与源anchor曲率为

\[
J_S(i,:)=\nabla_\theta m_\theta(x_i)|_{\theta=0},\quad
A=W^{1/2}J_S,
\quad W_{ii}=\frac{p_{0i}(1-p_{0i})}{2n_{y_i}},
\quad A=U\Sigma V^\top.
\]

W使用balanced-mean权重及共同数值anchor；不把它称为真实噪声协方差或未来信息。奇异值正值容差固定为max(1e−10,1e−6·最大奇异值)，并同时保留全谱和阈值前数值，不能把被截断的小正值说成数学零值。

设r为阈值下的正秩，q=min(2,floor(r/2))。高信息条件取最大的q个正奇异方向，弱信息条件取最小的q个正奇异方向；两者互不重叠。随机条件在同一正行空间里抽取q维Haar子空间，固定5个随机重复。q由支持输入和固定规则决定，不看query。

记录Top与Weak的谱间隔。边界奇异值相同或近似相同时标记方向不唯一/信息分离不足，使用预先固定的数值确定性规则处理并保留总体结果，不能看query后旋转或删除这些episode。谱阈值是数值定义，不是置信水平。

当q=0、空支持或单类支持时，方向比较的全部匹配条件共同返回EA并记录原因；保留在总体结果中，不能删去困难episode。完整SGD和其他基线按各自预注册fallback执行。

所有拟合统一最小化同一个支持目标：L(θ)=(1/2)Σc mean_{i:yi=c}[softplus(mθ(xi))−yi·mθ(xi)]+.01‖θ‖²。只使用支持标签；采用balanced BCE而非relative_dro，不新增目标query正则。θ零初始化，每步SGD后投影至‖θ‖≤.15，学习率.05，固定10或100步；**100步为主要强拟合剂量**，10步为预注册剂量复核。这里是在独立新协议中冻结这些取值，不修改R1的注册实现。子空间条件令θ=Va，优化a；相同q、正交坐标、学习率、迭代数和惩罚。

## 5. 实验A：同容量的方向干预

| 条件 | 空间自由度 | 作用 |
|---|---:|---|
| EA | 0 | 强anchor |
| Full-SGD | 4 | 原参数族中的空间拟合；head固定 |
| Top-q | q | 支持集约束较强方向 |
| Random-q | q | 同容量、同原参数族的随机方向，5次重复 |
| Weak-q | q | 最小正奇异值方向；诊断性对照 |
| Shrink-Full | 4 | Full-SGD普通标量缩小；区分方向与少改预测 |

每个支持集先拟合并保存未缩放更新，输出原始幅度结果，以及按共同参数Frobenius范数缩小的次级结果；**主要方向比较使用下面的共同函数幅度条件**。参数范数匹配与函数RMS匹配是两个独立控制层，不能假称任意方向能同时满足两者。单独Top优于Full仍不能排除容量变化，必须看Top对Random。

### 共同参考预测改变量

在固定参考输入C上定义

\[
\rho_C(\theta)=\sqrt{|C|^{-1}\sum_{x\in C}[m_\theta(x)-m_0(x)]^2}.
\]

C沿用预先冻结的参考预处理：C本身的无标签参考对齐只拟合一次，之后保持固定，不对每个目标episode重新估计。参考上的m0(C)指这套公共参考anchor，目标支持/query的m0则使用对应EA_S；不把两者混写。τB取先导支持拟合得到的该预算Full-SGD10参考RMS中位数，规则预先固定，不以先导/目标query优劣搜索τB。

主要匹配家族取ρ*=min(τB，各未缩放Top/5个Random/Full的ρC)。每个条件只用α∈[0,1]缩小其更新，使ρC(αθ)达到同一ρ*（确定性括区间求根，绝对容差1e−5）；**不放大更新以凑步长**。ρ*=0时共同返回anchor。记录α、匹配误差、参数范数及所有支持损失。

Weak是诊断性次级对照，单独与Top匹配到ρweak=min(主要ρ*, 未缩放Weak的ρC)，保存这份额外Top输出。它不进入主要家族的最小值，避免其接近零的响应将全部主要对照压成零。不能把不同ρ的Weak和主要Top直接当作同幅度检验。

Shrink-Full就是同一Full更新达到ρ*的标量收缩。原始幅度、参数范数和函数RMS是不同控制层次，不能声称同时完全匹配支持损失下降。支持拟合差异应被报告，而不是用目标query反向挑选“相同损失”的点。

未来query的RMS/KL和翻转率只在权重封存后计算，属于结果诊断，**不用于匹配、缩放或选方向**。参考RMS匹配不保证未来query的RMS也相等，这个差异正是需要观察的外推现象。

## 6. 实验B：删除真实更新的弱约束成分

仅注入人为零空间噪声再观察性能下降，不足以解释现有适配。主干预使用上述head固定的Full-SGD100真实更新θhat：

1. 在θhat处重新计算仅支持集的Jacobian，按同一规则确定q个弱正方向及投影Pweak。
2. 得到θdrop-weak=(I−Pweak)θhat。
3. 同一正行空间中抽取同q的5个随机投影，得到θdrop-random。
4. 加入原始θhat的普通标量收缩作为第三个对照；三类结果用**自己的匹配家族**按第五节规则匹配参考RMS，不与实验A强行共享同一ρ*。
5. 直接预测，不用query选哪个删除版本，也不事后追加优化把支持损失凑齐。

最终Jacobian沿用初始EA概率计算的Fisher权重，以避免改变曲率权重混淆方向删除。记录初始与最终支持谱中的真实弱成分能量、删除量和未来影响。若实际更新几乎没有弱成分、删除弱方向不优于同维随机删除，或结果完全由普通收缩解释，则主假设不获支持。

必须报告真实非线性margin改变量与Jθ的偏差。线性模型里零初始化SGD始终位于支持Jacobian行空间；因此**精确零空间不一定参与自然更新**。本研究针对弱约束正方向，而不是预设“SGD沿精确零空间过拟合”。局部线性近似差的episode保留在主分析中，并单列剂量与近似偏差，不通过事后删除来改善结果。

## 7. 实验C：head竞争与已知扰动

在A/B先导完成后再展开，不进行所有因素的巨大笛卡尔积。即使A/B不支持空间方向解释，以下预声明head竞争与已知扰动仍可在开发数据上检验竞争解释；这不授权开启新数据确认，也不允许据此改写六项主要比较。

- **Head交互**：Top/Random各加bias-only与完整65参数head两档，与主实验head固定作配对。另列低容量4特征+bias头作为强参考。共同RMS计入空间和head的总margin修正，同时缩小两个参数块；容量对比不混称“只改变方向”。
- **已知持久空间偏移**：仅开发数据，向S与固定Q施加同一预先登记的小幅可逆空间变换；增加已知逆变换oracle，证明这组数据存在可纠正的空间变化。
- **仅前缀空间偏移**：同一变换只作用S，Q保持原输入。检查“支持代表未来”这一前提失效时的结果。它是明确的人为压力条件，不等同于真实EEG时变机制。
- clean/持久/仅前缀三条件共享原始UID、标签、预算和源模型。shift大小及两个固定生成元由开发阶段冻结，query不参与选择。oracle只用于人工变换诊断，不进入真实数据主方法、选择或性能优越性主张。

完整head在n≤20上常满行秩，此时对head空间作精确自由投影后，空间Jacobian的Schur残差为零。该结论只关乎支持位置的局部表示；加ridge产生的非零量来自约束/先验。不能把本研究的head交互结果写成“发现了独立的新支持信息”。

Head交互拟合在同一balanced BCE上加入.001·(‖δw‖²+δb²)/65，δw始终表示在原64特征坐标中的物理向量；bias-only令δw=0，低容量头令δw=P4a。分母固定65，不按各条件可训练参数数目重新缩放。Head更新学习率.01、零初始化、与空间相同迭代次数。方向谱仍由初始共同冻结head计算，head自由度不是新增的可辨识性证据。

## 8. 强参考与可复用结果

本执行包重新拟合并逐事件配对的基线为正确EA、Frozen EEGNet、完整空间SGD10/100（分类头固定）、head-only bias/低容量/full，以及Top/Random与head交互。原生联合空间+head SGD10/100、R3保护、R4冻结交叉拟合、R9预声明代表和R10 profile/MAP保留为历史探索性上下文；本执行包不冒称已在新参考集和封存协议下重新运行这些旧方法。历史表与新比较独立展示；只有证明源/会话/query UID及评价协议一致后，才另行制定可配对复核，不直接拼表进入六项主要比较。R11待完整冻结报告后只能按预先规定的规则补作描述性上下文，不能边看部分成绩边选最优。

这些是上下文与算法价值参考，不能替代A/B的同容量同幅度对照。R4旧标记EA存在实际运行head_newton的错误，禁用该错误参考；仅复用输入、支持/query UID、源检查点、执行实现及评价版本均相同的正确结果。NLL统一概率floor1e−12；不同历史NLL不能直接混检。

最小可交付研究先完成A/B，而不是先展开全部head、噪声、shift、空间几何组合。24是参与者-seed**调度块数**，每块包含多会话、5预算、全部配对方法及随机重复，并非24次fit或24个独立受试者。参考、Jacobian、source前向与完成结果按身份复用。

先导继续方向路线的具体规则：在B20的8名开发参与者上，(a) Full-SGD100相对EA呈现平均支持BCE下降且未来NLL上升；(b) 至少一半合法episode的真实弱成分删除在C上产生RMS>1e−4的变化；(c) Top−Random与DropWeak−DropRandom的参与者平均BA差均>0、NLL差均≤0；(d) Top−ShrinkFull的平均BA差≥0。任一不满足则不启动独立数据确认；保留负结果，可在同一冻结设计中检验head竞争解释，不因其失败增加维度/半径后再试旧目标集。这是小样本开发的继续规则，不是显著性证明或未来风险保证；阈值1e−4只用于排除几乎没有实际干预的情形，不定义生理意义上的重要程度。

## 10. 统计、证伪与论文主张

详细规则见[STATISTICS_ZH.md](STATISTICS_ZH.md)。B20的六条主要比较为：Top−Random的BA/NLL、DropWeak−DropRandom的BA/NLL、Top−ShrinkFull的BA、Top−EA的BA，统一Holm控制；其他预算为冻结次级分析。参与者等权，会话/seed/随机重复不增加独立N。

| 结果 | 允许的结论 |
|---|---|
| 同容量同RMS的Top优于Random，真实弱成分删除也优于随机删除，并优于普通收缩 | 支持在指定模型/协议下具有可干预性的方向失效机制；仍需独立队列复现 |
| 所有保护收益都被ShrinkFull复现 | 更支持幅度解释；放弃方向机制的主创新表述 |
| 只在65维head出现，冻结head时没有 | head过拟合/竞争解释更强；不能泛化为空间适配普遍失效 |
| 人为噪声能破坏，但自然更新不含对应成分 | 正对照成立，真实原因未证明 |
| 机制对照有差异但Top未超过正确EA | 可写机制研究，不能宣称获得更强适配算法 |
| 仅旧holdout/Pan/Weibo有正结果 | 探索性证据；不是新的独立泛化确认 |

同容量、同参考函数幅度均不是随机对照临床试验意义上的总体因果识别。这里的“干预”指固定数据和模型下对参数更新的受控算法干预；结论限于相应范围，不上升为生理因果机制或未来风险定理。

## 11. 学校计算与结果交付

资源计划沿用最近要求：**4个并行作业，每作业1GPU、16CPU、64G内存**。动态领取完整的参与者-seed对照块，同一块内完成配对条件，减少频繁进程启动及重复源验证。执行包仅在用户终端显式使用`--prepare --submit`后提交新作业；本地开发与验证不调用学校Slurm。原始设计配置保留为历史文件，准备阶段生成绑定实物SHA的执行计划，支持集尺度另由校准任务冻结。

未来实现要求：一次发布前兼容性检查；worker启动时读取冻结模型/字典并建立进程内缓存；科学任务、运行监控和上传互不控制。禁止周期自动SIGINT刷新、因为监控写失败终止fit、网络失败重训、或每次fit遍历全源档案。工件身份一次性绑定，完成回执只对应实际完成；异常记录该块、保存已有checkpoint并有界重试，不能伪造成功或无限重试同一科学错误。

通道A优先上传完整参与者/会话/预算配对表、支持损失、谱/更新分解、匹配剂量、纠错引错、BA/NLL/Brier、统计与配置；通道B独立归档原始预测、适配权重、Jacobian/谱及验证轨迹，附SHA和回执。上传延迟不影响计算。两通道都保留失败、fallback与未完成分母。

建议最终图：已有支持拟合—未来风险冲突；同容量同RMS方向干预；真实更新弱成分删除；预算×head交互；持久/仅前缀shift的正对照；EA对比与成本。主论点围绕同一个可被推翻的问题，不把每张图都包装成一个新模块。

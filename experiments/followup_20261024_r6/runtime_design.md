# 第六轮执行结构

hpc_gpu1一个节点、一个Slurm作业取得3GPU、36CPU、164G共享主机内存。内部三个独立单卡worker动态领取198项DAG任务，满足字典依赖后优先新Pan评价；不用大数组、srun或DDP。

学校既有源EEGNet、源参考和Stieger缓存只读复用；新Pan裁剪缓存随安装器交付，计算节点不下载原数据或环境。数值配方绑定代码、数据内容及生产字典身份，安装目录本身不是科学差异。

每10个outer更新保存双代checkpoint及随机状态；评价逐会话原子保存。完成项复用、未完成补缺失部分。任务失败保留error/traceback，独立任务继续；失败依赖不冒充完成。

控制器保存提交意图、回执、状态与尝试历史，处理QoS等待及确认丢失，同计划最多一个三卡allocation。每30秒输出三槽实际计数。单次时限前保存，退出75后对账续交；主动取消保持停止，无累计12小时限额。

独立监控每180秒更新报告和GitHub汇总。主16项NLL/BA家族仅针对新Pan，覆盖未齐正常回传部分结果，不停止训练。上传/报告错误独立重试，模型和完整结果先写学校共享目录。

发布包含可续传的小bootstrap与固定SHA自包含包。超时保留分片持续重试；完整缓存直接断网使用，解包后不再访问原数据网站。验证与日志入口见README、RUNBOOK和VALIDATION。

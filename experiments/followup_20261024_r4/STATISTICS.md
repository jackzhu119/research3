# 第四轮统计与模型选择约定

本轮是 **在已复用内部参与者上的探索性算法比较**。此前轮次已经使用相同内部留出参与者，因此新的代码、额外种子、同一轮内的多重比较校正，均不能将本轮重新变成全新盲测或前瞻确认。不得根据前三轮内部留出结果挑选一个成功设置，再把该设置在第四轮的同批参与者上称为独立发现。跨轮次反复探索的选择偏差也不会被本轮Holm自动消除。

`paper3r4.report.build_report(plan)` 只读本轮任务目录的 `result.json` 和逐会话评价JSON，不读取原EEG缓存、不改变训练结果、不提交或取消作业。报告错误返回 `status=ERROR`，监控随后重试，训练和其他任务继续。统计工作不是学校端启动前必须重复运行的门禁。

## 支持集内选择和未来评价分离

每个会话严格沿用原始事件顺序定义支持预算。无效QC事件仍占用前缀名额，不从未来补足。B4/8/12/16/20使用同一B20之后定义的查询身份；短预算不能通过改用更早或更容易的查询获得额外优势。比较算法、种子和支持预算时，查询trial UID、标签和顺序签名应相同。

若本轮方法用支持内交叉验证选择正则或半径，候选网格、折划分、损失函数、失败处理和保守tie-break顺序必须在读取该会话未来查询前固定。完整过程为：只在支持前缀中划折；每个候选仅拟合折内训练信号与标签；对该折保留支持试次计分；按既定规则选候选；最后用全部有效支持试次重新拟合选中候选，再评价未来查询。查询信号统计也不能参与模型或阈值选择。

主选择规则可以使用预定的one-standard-error规则：在支持CV最佳损失加一个预定标准误启发式范围内，按事先固定的保守顺序选模型。它是少样本选择启发式，不是“最佳模型准确率的95%置信区间”。LOO训练折大量重合，EEG试次也可能相关，因此按折损失直接计算的标准误不能包装为独立样本的严格覆盖保证。若用近似LOO而非逐折重拟合，应明确记录近似身份，并在算法测试中与小样本精确重拟合对照。

缺少两类、有效折不足、数值拟合失败时，程序沿用明确记录的回退规则；不能删掉这些会话以只展示成功选择的结果。保存所选候选、候选网格大小、有效折数、候选拟合次数、规则及回退原因。CV全部候选的拟合、计分、选择、完整支持重拟合时间都计入 `calibration_seconds`，不能只报告最后一次拟合的耗时。

字典的元训练使用元训练参与者，最佳字典只由元验证参与者选择。内部留出数据只用于已固定任务的评价。支持内选择是每个目标会话适应方法的一部分；它不能偷偷访问未来标签，也不替代字典选择的参与者级分离。

## 参与者是统计单位

每个方法对同一参与者、会话、种子和查询集进行配对。先对该参与者各会话的算法差取均值，再在参与者内对可用的预定种子等权平均，最后对参与者等权平均。试次、会话、候选参数和三个随机种子均不是新增的独立受试者。不能把11人×3种子写成33个独立样本。

每个指标使用自己的完整配对会话，不将缺失量补为0，也不让缺失的次要指标改变BA分母。报告有效参与者数、会话×种子行数、被排除的次要指标行数和参与者种子覆盖。已声明完成的任务若缺少它所声明的会话文件、存在重复、概率无效或查询签名冲突，报告应标明数据一致性错误，不能静默当成合法排除。该错误不会反向取消其他运行任务。

## 固定主要比较与区间

`plan.comparisons` 在结果读取前固定本轮主要比较家族。主要评价坐标为计划指定的内部留出、B20、clean条件。所有主要比较涉及的组必须各自完成全部预定种子，候选与基线会话网格一致，至少存在两位有效参与者，才计算整个家族的p值。无关的敏感性、压力或外部迁移任务尚未完成，不阻止主要家族完成；主要家族仍缺组或种子时，已完成效应与描述区间照常显示。

家族全部齐备后，对每个参与者的种子平均配对BA差实施双侧sign-flip检验。11位参与者枚举全部2048个符号向量；其零假设需要配对差的符号对称性，而不是凭空制造随机分配。Holm按完整预定家族一次调整。正向结果字段 `positive_evidence` 同时要求BA差为正且Holm p<0.05，含义仍是探索性内部证据。运行中不随每个新种子反复查看显著性并提前停在有利结果。

区间使用20,000次确定性参与者bootstrap，保留每人的配对和种子平均结果。统计随机种子为20261018。95%区间是逐项、未作同时校正的百分位区间，条件于这次划分、固定流程和已有种子，不是临床总体效能保证，也不是跨数据集抽样的不确定度。有效参与者少于2时不提供区间或检验。

支持预算曲线、正则/半径敏感性、压力条件、外部迁移、概率质量、纠错/负翻转、校准耗时、选择频率和谱诊断均为描述性输出，不扩大也不重设主要Holm家族。若在这些输出中发现新机制，下一轮应预先固定该机制并尽可能在新的参与者或数据域验证，不能把本轮事后最优项写成预注册主假设。

## 指标定义与CV选择频率

BA、负翻转和纠错质量均按类别等权。负翻转指原模型正确而适配后错误的无条件类别平衡质量，纠错指原模型错误而适配后正确的质量，因此 `BA_gain = corrected_error_rate - negative_flip_rate`。不把“在原正确样本中错误的条件比例”混入同一恒等式。二分类Brier、NLL和10等宽置信度bin ECE也按类别平衡权重计算；报告只读保存概率，不再拟合新的校准器。

BA和率差以百分点报告，耗时以秒报告，概率评分以其原单位报告。`bce`按工作者保存值显示，独立重算的 `nll_balanced` 采用报告中的明确类别平衡定义。

工作者可在 `diagnostics.cv` 写入：

```json
{
  "selected_candidate": "head1-radius0.05",
  "selected_config": {"head_l2": 1.0, "radius": 0.05},
  "selection_rule": "one_standard_error",
  "status": "SELECTED",
  "valid_folds": 20,
  "n_candidate_fits": 120
}
```

它是接口示例，不代表实际最终网格或算法结果。数值型嵌套诊断继续按会话→种子→参与者等权汇总。`cv_selection_frequency.csv` 对 `selected_*`、`chosen_*`、所选配置和选择状态生成类别频率，同样先对参与者内会话和种子求平均；附带原始选择会话数和缺失元数据覆盖。一个人的许多会话不能压倒另一个只有少量会话的人。类别频率是机制描述，不把候选次数当独立样本做显著性检验。

不使用CV的固定基线无需这些字段，仍可完成报告。逐fold标签、分数和预测数组留在本地，不转成选择频率表。完整本地结果始终保留；GitHub发布汇总表，网络失败只重试同步。

## 资源、外测与解释范围

本轮学校目标为 `hpc_gpu1`、三单卡并行，各16CPU/64G主机内存、A100-SXM4-80GB。更多CPU/GPU不增加独立统计样本，也不改变参与者级推断。节点截图的即时空闲资源不保证提交时仍然空闲；配额和排队属于运行状态，不属于科学排除条件。

若沿用已准备Weibo外测，继续只称发布顺序LR子任务前缀稳健性：真实物理采集顺序和run身份未知，B20也不是整场前20条全部任务。它能补充跨数据域描述，不能自动改称相同临床采集预算的前瞻确认，也不能用其未来标签为核心方法重新选参数。

所有软件测试使用合成预测记录或合成EEG输入。通过测试证明实现与统计账目契约，不证明准确率提升、学校GPU性能或论文创新成立。

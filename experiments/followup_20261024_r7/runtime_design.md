# 第七轮执行结构

`hpc_gpu`一个节点、一个Slurm作业取得3张A100-PCIe-40GB、36CPU与128G共享主机内存。三个独立单卡worker各获12CPU亲和组，动态领取273项DAG任务（15字典、72内部核心、72敏感性、21参考、93Pan）。字典依赖满足后优先Pan重复评价；不用大数组、srun或DDP。每个GPU槽的显示内存份额为128/3GiB，实际Slurm申请始终为共享总128G。

学校既有源EEGNet、源参考和Stieger缓存只读复用。第六轮已准备的Pan2023裁剪缓存随第七轮安装器交付；它不是本轮新取数或新的首次盲测。计算节点不下载原数据或安装准备环境。数值配方绑定代码、数据内容及字典生产身份，安装目录本身不是科学差异。同配方重新打包时保留已准备任务的原输入路径与活跃控制器配置，避免文档更新破坏已有完成项。

每10个outer更新保存双代checkpoint及随机状态；评价逐会话原子保存。完成项复用、未完成补缺失部分。单任务失败保留error/traceback，独立任务继续；失败依赖不冒充完成。支持秩不足和数学诊断不是学校启动门槛。

控制器保存提交意图、回执、状态与尝试历史，处理QoS等待及确认丢失，同计划最多一个三卡allocation。每30秒输出三槽实际计数。单次时限前保存，退出75后对账续交；主动取消保持停止，无累计12小时限额。

独立监控每180秒更新报告和GitHub汇总。主24项NLL/BA比较族针对Pan B20 clean；覆盖未齐时正常回传部分结果，不停止独立训练。上传和报告错误独立重试，模型及完整结果先写学校共享目录。每轮GitHub路径与本地输出互相独立。

发布包含可续传的小bootstrap与固定SHA自包含包。连接或下载超时保留分片持续重试，raw/API双端点；完整缓存可直接断网使用，解包后不访问原数据网站。安装验证限于发布包与既有根目录/解释器、固定计划，不重新跑学校全量test/pilot或数据树扫描。验证与日志入口见README、RUNBOOK和VALIDATION。

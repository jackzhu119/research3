# 论文3第五轮：相同校准预算下的旋转—相对增益耦合

状态：第五轮独立方案与程序已准备，尚未向学校提交作业；没有第五轮准确率或显著提升结果。本轮紧扣冻结EEGNet、目标会话前20个已获取试次、少量空间校准参数的论文主线。

将同一个低维生成元拆成反对称部分K与对称无迹部分S，比较 `exp(K+S)`、`exp(K)exp(S)`、`exp(S)exp(K)` 及候选对称组合 `exp(K/2)exp(S)exp(K/2)`。所有模型仍使用同一rank-4参数θ与同一分类头，不将旋转和增益各增设一套参数。候选结构同时保留旋转/伸展分解与参数取反时的逆一致性；旧联合指数也具有逆一致性，不能把它写成旧算法不可逆。

主问题是：**在相同采集前缀、相同参数预算和匹配优化预算下，耦合方式是否改变跨会话校准收益？** 三种分解在共享θ时具有相同白化增益谱、旋转极因子及扰动酉不变范数，适合检验相对方向耦合；经非正交参考重着色后，原CAR坐标的欧氏幅度不一定相同。理论性质和保证边界见 [DESIGN_ZH.md](DESIGN_ZH.md)。

105不是105次完整训练；只有12项训练低维空间字典，冻结源EEGNet及数据继续复用。核心48项各评价B4/8/12/16/20，始终使用同一个B20之后的未来查询。另在12项共同字典核心任务中运行72个耦合漂移条件：两种非交换顺序和同谱可交换对照，各两档强度；相同变换同时作用支持与查询，标签和付费前缀身份不变。精确矩阵在 [EXPERIMENT_MATRIX.json](EXPERIMENT_MATRIX.json)。

主要方法先用共同身份切线做10次Newton初始化，再进行5步各自真实非线性变换上的支持目标精化与回溯。只换预测变换、沿用共同θ的实验单独标记为机制探针，不混入部署方法主比较。8项主要比较预先固定，并按参与者配对、三种子内聚合后统一Holm；既有内部留出被前轮使用过，仍属于探索性复验。详见 [STATISTICS.md](STATISTICS.md) 与 [LITERATURE.md](LITERATURE.md)。

# 论文3：第三轮空间校准实验

状态：程序与实验设计已准备，尚未向学校提交第三轮作业。第一、二轮仍使用各自原有目录与分支。这里没有第三轮准确率或显著性结果。

本轮研究：冻结 EEGNet，只用目标会话前20个支持位置，学习低维空间变换及小分类头。新增解析切空间、消去分类头干扰后的空间曲率、信息量自适应收缩和支持集预测变化约束，并分别检验求解器、正则强度和重新学习字典的贡献。

| 内容 | 逻辑任务数 | 目的 |
|---|---:|---|
| 字典训练或复用 | 21 | 旧SGD字典的2/4/8维版本、3种新联合字典及匹配正则SGD字典，3种子 |
| 核心比较 | 78 | 相同字典比较12种校准设置，再交叉比较新字典与匹配正则字典 |
| 敏感性评价 | 72 | 维数、半径、分类头先验、迭代数、信息尺度、KL阈值 |
| 支持集EA参考 | 3 | 低成本协方差对齐参考 |
| **核心合计** | **174** | **只有21项涉及字典训练，其他主要是校准与评价** |
| 可选Weibo迁移 | 18 | 独立数据上的发布顺序LR子任务稳健性，复用本轮字典 |

主比较使用相同分类头先验 `head_l2=0.1`；原始 `0.001` 的SGD另列参考。新字典的主要比较也使用训练阶段同为0.1的SGD字典，排除训练正则变化的混杂。核心方法报告支持预算4/8/12/16/20，始终使用相同B20之后的查询集。6种压力条件只在18项选定核心评价上、B20预算运行，共108个额外评价组合。完整公式和假设见 [DESIGN_ZH.md](DESIGN_ZH.md)，具体任务清单由 [plan.py](paper3r3/plan.py) 生成。

学校默认资源为已记录的 `hpc_gpu`，最多3个独立单卡任务，各12核CPU、64G主机内存，使用现有cu121环境。可在配额允许时传 `--cpus 24 --memory 128G`，改变这些调度参数不改变实验数值配置。不重新安装环境，不重复全量pytest、pilot或冻结数据全盘扫描；不存在累计12小时限制。

启动和续跑见 [RUNBOOK_ZH.md](RUNBOOK_ZH.md)。同一条启动命令可恢复未完成工作；已完成任务不会重新训练。训练每10次outer更新保存轮换断点，校准评价逐会话保存。QoS配额不足时控制器等空位；单任务错误保留明确日志，其他独立任务继续。学校Slurm每次分配的时限仍然存在，提前信号触发保存后可续跑。

GitHub自动同步到本分支 `monitoring/paper3-round3/status.json`，每180秒尝试一次，网络故障只重试同步，模型训练不因此终止。完整预测、checkpoint、报告CSV保存在学校本地，公开回传的是汇总数据。Weibo独立阶段使用 `weibo-status.json`。

新增外部数据已实际下载10人原MAT并验证SHA和预处理一致性：1,580条有效左右手试次，200条B20支持位置，1,380条查询，衍生缓存约11MB。它的真实物理采集顺序不可核实，因此仅用作**发布顺序LR子任务稳健性**，不能称为严格真实采集前20条的前瞻确认。见 [EXTERNAL_DATA_NOTES.md](EXTERNAL_DATA_NOTES.md)。主实验无需等待外部数据。

数值单元测试、实际合成数据训练到报告的隔离入口、安装器与模拟Slurm验证见 [VALIDATION.json](VALIDATION.json)。兼容环境为Python3.12.3、PyTorch2.5.1+cu121、NumPy2.2.6；验证主机没有GPU，学校A100实跑仍需实际作业确认。数据效果与显著提升尚待实验，不承诺已找到最优算法。

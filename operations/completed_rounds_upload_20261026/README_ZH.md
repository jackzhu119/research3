## 启动

在学校 `login1` 粘贴 `delivery/RUN-ONE-LINE.sh` 的整行指令。仅使用现有 Python3.12 与现有 GitHub 凭证；不安装依赖、不导入 Torch、不提交或取消作业、不读取原始EEG数据。

成功返回 `COMPLETED_ROUNDS_UPLOAD_BACKGROUND_STARTED` 且 `terminal_can_close: true` 后，即可关闭终端。两个进程都重定向输入输出并创建独立会话，持有独立锁；同一指令重复执行会复用已经运行的通道。

工作目录：`$HOME/paper3-completed-results-upload`。

- 快通道日志：`paper/upload.log`，状态：`paper/status.json`。
- 完整归档日志：`full/upload.log`，状态：`full/status.json`，文件打包细节：`full/progress.json`。
- 启动回执：`STARTED.json`。PID和握手只证明后台启动，远端指针证明已核验上传完成。

网络错误和暂时缺少凭证会在后台重试；不会使训练中断。源凭证只读取，不进入程序包或结果。旧第六轮归档进程若仍持锁，本完整通道等待它，其他轮次继续。已上传的第二、三、七轮不进入本次任务列表。

## 快通道：供分析和论文写作

每轮先按显式计划采集以下内容，不递归读取逐试次输出树，不重新统计论文结果：

1. 原始计划、已有报告、完整CSV、完整报告缓存和运行修复记录；超过64MiB的文本仍保留全部原始字节。
2. `analysis/task-results.jsonl`：每项任务的完整原回执，保留身份、源模型/数据标识、选择结果和修复来源。
3. `analysis/condition-summaries.jsonl`：计划声明的预算、场景、分区所对应原摘要，保留参与者编号、已有BA/BCE/NLL值、会话查询签名和原文件SHA。这里只复制已存值，不生成新的p值、平均数或结论。
4. `analysis/task-index.csv`、`collection-metadata.json`、`source-index.json`：完成数、缺失项、报告时效和出处。

已有报告可能早于任务完成；这一点在 `reports_stale_or_unknown` 明确保留。只要原参与者摘要齐全，就可以先据此开展BA/NLL配对分析，而不把旧报告的PARTIAL误当成实验缺失。报告读取失败或关键证据缺失会先上传可读资料并保持PARTIAL，随后重试，不宣称全部补齐。

目的地分别为 `paper3-results:results/paper3/round-04|05|06|08/paper-data/<snapshot>/`；每轮最终索引为 `PAPER_DATA_LATEST.json` 和 `PAPER_DATA_ZH.md`。原字节以约1MiB的UTF-8片段保存，含偏移、每片及整文件SHA；完成指针在所有片段的完整远端GET校验后才发布。不会再删去参与者、会话或差值字段。

恢复某个CSV、JSON或JSONL：读取全局manifest中的 `files[].manifest`，再用公开的 `transport/restore_source.py --manifest <该路径> --ref <回执commit> --output <新文件>`。它按原字节恢复，拒绝覆盖已有文件。

## 慢通道：完整科学输出归档

独立低CPU优先级进程逐轮读取已完成任务的预测、验证轨迹、选择文件和checkpoint，生成32MiB归档片并上传GitHub Release，保留源文件。上传分片按SHA核验，可复用已经准备好的本地归档；所有片段和索引成功后，才发布每轮 `LATEST.json`。

范围是本轮声明的科学输出，不包含原始EEG、放在轮次之外的共享源模型、安装环境或凭证。大于Git单文件限制的逐文件清单也有精确分片形式，并提供恢复说明。本通道与快通道的指针各自保留，任一通道不等待另一通道。

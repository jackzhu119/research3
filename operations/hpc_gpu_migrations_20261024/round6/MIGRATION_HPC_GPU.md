# 第六轮迁移至 hpc_gpu：保留原结果继续运行

此包只更换第六轮的运行资源和调度配置。原算法、数据选择、198 项任务、数值配方、训练断点和已完成结果继续使用；不创建另一轮实验，也不从零开始训练。

| 项目 | 本次资源 |
|---|---|
| 分区/资源组 | `hpc_gpu`，A100-PCIe-40GB |
| Slurm 分配 | 一个节点、一个普通作业，无数组 |
| GPU | 同一节点三张，三个独立单卡工作进程 |
| CPU | 整作业 36 核，每槽 12 核亲和组 |
| 主机内存 | 整作业共享 `128G`，不乘三 |
| 等效 Slurm 请求 | `--nodes=1 --ntasks=1 --cpus-per-task=36 --mem=128G --gres=gpu:3` |

`--cpus 12` 是每个 GPU 槽的 CPU 数；`--memory-total 128G` 是整个作业的共享内存。每槽约 42.67GiB 只是等分规划，不设置进程虚拟地址空间硬限制。GPU 的 40GB 显存与主机内存分别计算。`hpc_gpu` 是分区名，不是指定主机名；空闲三卡还需落在同一个节点且有足够 CPU、内存，条件未满足时正常排队。

## 如何切换

先完成对原第六轮控制器和作业的核对与交接，再执行新包。原控制器会持续保留它启动时的 `hpc_gpu1/164G` 设置；只改启动命令不能改变正在运行的分配，也不能同时保留两个控制器调度同一输出目录。交接时应让原工作进程保存断点，并确认原作业不再写入，再启动本包。停止或取消其他轮作业不属于这次迁移。

安装后的等效启动命令如下。将 `NEW_PACKAGE` 替换为新包的实际绝对安装路径；使用本次发布的固定下载指令时，这一步由安装器完成。

```bash
NEW_PACKAGE=/新包的实际绝对安装路径
/public/home/zhuziyuan/.venvs/paper3-hpc-cu121-offline/bin/python -I -S -B -u "$NEW_PACKAGE/START.py" --partition hpc_gpu --gpus 3 --cpus 12 --memory-total 128G --submit
```

默认继续写入 `/public/home/zhuziyuan/projects/paper3/runs/followup_20261024_r6`。若原第六轮使用自定义输出目录，应加上原来的 `--output /原输出目录`，不要为了迁移另建结果目录。没有 `--submit` 时仅准备，不启动训练。后续续跑仍用相同命令。

## 必须保留的原文件

- 原输出目录中的 `plan.json` 保持原内容与任务顺序。新包核对数值配方及路径对应的数据内容后采用已有计划，不重写其任务路径。
- 原安装目录继续保留。已有计划的 Pan `external_manifest` 使用原绝对路径，旧 worker 的任务身份也包含该路径；不要删除旧包或把原计划的路径批量替换到新包。
- 原 `root`、字典输出路径、任务目录、双代 checkpoint、`latest.json` 和完成回执保持不变。完整字典、已完成任务直接复用，未完成训练恢复最近可用更新，已保存评价只补缺失会话。

本包携带同一份 Pan 缓存，便于新安装和交付核对；迁移已有计划时继续读取计划原来指向的缓存。计算节点不下载原 MAT，不安装依赖，不重跑全量 pytest、pilot 或全数据树验证。实际任务读取所需模型和缓存仍会产生必要 I/O。

## 日志、续跑与 GitHub

`PREPARED` 表示资源和计划准备成功；`DETACHED_PROCESSES_STARTED` 表示登录节点后台进程已启动；回执的 `job_id` 表示 Slurm 已接收作业。节点日志出现 `TRAIN_PROCESS_STARTED` 后，再看三槽的任务、更新步数或评价会话数增长，才能确认实际计算推进。不能只看网页的“运行时长”。

节点日志继续位于原输出目录的 `logs/train-作业号.out/.err`，任务日志为 `logs/task-索引-attempt次数.out/.err`，三槽进度为 `allocation_progress.json`。原结果与 GitHub 第六轮记录延续，仍尝试同步 `paper3-r6-progress:monitoring/paper3-round6/status.json`；上传或报告失败独立重试，不要求重新训练。

不设累计 12 小时上限。单个 Slurm 作业仍受学校调度时限约束，默认 `5-03:00:00`；到期前请求保存，按已有控制器规则续交。明确主动停止和 `STOP` 标志会被尊重，不自动复活。迁移操作不应把“暂停待交接”误当成“实验已完成”。

从 A100 80GB 切到 A100 PCIe 40GB 不改变实验任务与已保存状态，但不能把跨设备续跑宣称为逐位等价。是否顺利获得三卡及真实 GPU 执行，以学校作业回执和现场日志为准。
